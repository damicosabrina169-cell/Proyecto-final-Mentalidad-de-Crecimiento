Proyecto Final

Documentando un desafío técnico mediante una mentalidad de crecimiento

Contexto

Durante el desarrollo de una página web trabajé en la organización del proyecto utilizando HTML, CSS y GitHub. El objetivo fue mantener una estructura clara, registrar correctamente cada modificación y mejorar la documentación del trabajo.

Problema

Durante el proyecto observé que algunos cambios se realizaban sin una organización definida. Esto dificultaba identificar qué modificaciones se habían realizado y hacía más complejo el seguimiento del trabajo.

Acciones realizadas

  • Organicé la estructura del proyecto para facilitar su mantenimiento.
  • Registré cada modificación mediante commits descriptivos en GitHub.
  • Revisé el contenido para mejorar la claridad de la documentación.
  • Realicé un post-mortem constructivo analizando las causas del problema sin buscar responsables.
  • Definí acciones preventivas para evitar que el mismo inconveniente vuelva a repetirse.

Aprendizajes

Esta experiencia me permitió comprender la importancia de documentar correctamente cada cambio realizado y utilizar el control de versiones para mantener un historial organizado del proyecto.

Reflexión sobre feedback radicalmente sincero

Durante este proyecto recibí observaciones sobre la organización del contenido y la documentación realizada. En lugar de interpretar esos comentarios como una crítica personal, los utilicé para mejorar el trabajo. Comprendí que un feedback claro, respetuoso y basado en hechos permite detectar oportunidades de mejora y fortalece el aprendizaje continuo. Esta experiencia reforzó mi mentalidad de crecimiento y la importancia de la comunicación efectiva dentro de un proyecto.
